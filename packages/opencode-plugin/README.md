# @vaur94/agz-memory-plugin

Optional exact-beta OpenCode V2 adapter for `@vaur94/agz-memory`.

Safe defaults are `mode: "off"`, `autoCreateProjects: false`, no bindings,
capture disabled, semantic backend `none`, eight cards, 4,800 characters, and a
300 ms retrieval deadline. See the repository README for configuration and
rollout guidance.
